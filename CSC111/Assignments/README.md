# CSC111 Assignments

These assignment briefs are original practice work aligned with the extracted
chapters. They are not copied from the textbook. Submit source files in the
chapter folder or in the location specified by your instructor.

## Assignment sequence

1. **Chapter 1 — Computer Systems Report:** Compare a personal computer's
   hardware components and explain how an operating system supports program
   execution.
2. **Chapter 2 — First C++ Program:** Write, compile, and run a program that
   displays a formatted student introduction and a short multiline message.
3. **Chapter 3 — Interactive Receipt:** Read item prices and quantities,
   calculate subtotal, tax, and total, and display a neatly aligned receipt.
4. **Chapter 4 — Grade Classifier:** Read a score, validate that it is in the
   allowed range, and display its letter grade using conditional statements.
5. **Chapter 5 — Data Summary:** Read values from a text file, calculate
   count, sum, minimum, and maximum, and write the results to an output file.
6. **Chapter 6 — Modular Calculator:** Build a menu-driven calculator whose
   operations are implemented as separate functions.
7. **Chapter 7 — Monthly Temperatures:** Store twelve temperatures in an
   array, then report average, highest, lowest, and the corresponding months.
8. **Chapter 8 — Search and Sort Utility:** Sort a list of integers and support
   both linear and binary searches, reporting the number of comparisons.
9. **Chapter 9 — Pointer Swap Lab:** Implement swap, minimum, and maximum
   operations using pointer parameters and demonstrate each operation.
10. **Chapter 10 — Text Analyzer:** Read a line of text and report character
    count, word count, digit count, and vowel count.
11. **Chapter 11 — Inventory Records:** Define a structure for an inventory
    item, read several records, and produce a value-ordered inventory report.
12. **Chapter 13 — Bank Account Class:** Design a class with private data,
    constructors, validation, deposit, withdrawal, and balance reporting.
13. **Chapter 20 — Recursive Toolkit:** Implement recursive versions of
    factorial, digit sum, and greatest common divisor, including base cases.

The extracted reading for each assignment is in the matching folder under
[Chapters](../Chapters/README.md). The syllabus remains the authority for
grading, due dates, and submission requirements.
