# CSC111

Course notes, labs, and assignments for CSC111 (Computer Programming I in
C++).

## Course layout

- [Chapters](./Chapters/README.md) contains the instructional material in
  textbook order.
- [Assignments](./Assignments/README.md) contains setup files and course
  assignments.
- [CSC111-Fall2025-Syllabus.pdf](./CSC111-Fall2025-Syllabus.pdf) is the
  authoritative source for the Fall 2025 course schedule and policies.

The chapter folders retain their textbook chapter numbers. Missing numbers are
intentional: only the chapters used by this CSC111 course are included.
