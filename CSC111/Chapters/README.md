# CSC111 Chapters

The folders below are arranged by the chapter numbers used in the course
textbook. The numeric prefixes are part of each folder name so that the
sequence remains stable in file browsers and source control.

## Recommended study order

| Order | Folder | Main topics |
| ---: | --- | --- |

Chapters 12 and 14–19 are not missing course work; they are not part of the
current CSC111 collection. Chapter 20 remains last because its textbook
number is 20, not because it is a renamed chapter 12.

Each chapter keeps its own `README.md` as the entry point for notes and future
examples. Add labs, source files, and exercises inside the corresponding
chapter folder rather than creating additional top-level chapter folders.
