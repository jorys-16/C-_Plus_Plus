# CSC211 Chapters

These folders follow the Spring 2026 CSC211 syllabus rather than the introductory CSC111 sequence. The course continues from classes into vectors, dynamic memory, files, inheritance, templates, the STL, and recursion.

## Recommended syllabus order

| Week/module | Folder | Main topics |
| ---: | --- | --- |
| 1-2 | [Chapter 13: Classes and OOP](./Chapter_13_Classes_and_OOP/) ([PDF](./Chapter_13_Classes_and_OOP/Chapter_13.pdf)) | Constructors, member functions, arrays of objects, OOP design |
| 3 | [Chapter 07: Arrays and Vector](./Chapter_07_Arrays_And_Vector/) ([PDF](./Chapter_07_Arrays_And_Vector/Chapter_07.pdf)) | Multidimensional arrays and `std::vector` |
| 4-5 | [Chapter 09: Dynamic Memory](./Chapter_09_Dynamic_Memory/) ([PDF](./Chapter_09_Dynamic_Memory/Chapter_09.pdf)) | Dynamic allocation and pointers to records/classes |
| 6 | [Chapter 12: Advanced File Operations](./Chapter_12_Advanced_File_Operations/) ([PDF](./Chapter_12_Advanced_File_Operations/Starting_Out_Chapter_12.pdf)) | Persistent structured data and file access |
| 8-9 | [Chapter 14: More About Classes](./Chapter_14_More_About_Classes/) ([PDF](./Chapter_14_More_About_Classes/Starting_Out_Chapter_14.pdf)) | Composition, aggregation, and operator overloading |
| 10-11 | [Chapter 15: Inheritance and Polymorphism](./Chapter_15_Inheritance_and_Polymorphism/) ([PDF](./Chapter_15_Inheritance_and_Polymorphism/Starting_Out_Chapter_15.pdf)) | Inheritance and virtual functions |
| 12 | [Chapter 16: Exceptions and Templates](./Chapter_16_Exceptions_and_Templates/) ([PDF](./Chapter_16_Exceptions_and_Templates/Starting_Out_Chapter_16.pdf)) | Exception safety and generic programming |
| 13 | [Chapter 17: STL](./Chapter_17_Standard_Template_Library_STL/) ([PDF](./Chapter_17_Standard_Template_Library_STL/Starting_Out_Chapter_17.pdf)) | Containers, iterators, and algorithms |
| 13-14 | [Chapter 20: Recursion](./Chapter_20_Recursion/) ([PDF](./Chapter_20_Recursion/Chapter_20.pdf)) | Recursive algorithms and tracing |

Each chapter has the same notes, examples, exercises, solutions, and review layout used by CSC111. The numeric folder names retain the textbook chapter numbers; the table above is the syllabus study order.
